## 🎯 项目介绍

本项目是一个 **前后端分离** 的智能旅游助手系统：

- **🧠 AI 行程规划**：输入目的地 / 预算 / 天数，调用大语言模型自动生成**每日行程、预算分配、出行贴士**。
- **💬 AI 旅游咨询**：全双工聊天，支持 **SSE 流式响应（打字机效果）**，体验堪比一线 AI 产品。
- **🎨 多巴胺马卡龙 UI**：6 色循环渐变 + 玻璃拟态 + 弹性动效 + 3D 卡片，视觉辨识度拉满。
- **📱 移动端优先**：基于 Vant UI，完美适配手机尺寸，GitHub Pages 扫码即看。
- **🌏 多模型兼容**：支持 DeepSeek / 硅基流动，API Key 改 yml 一行即切。

## 🚀 快速开始（3 步 2 分钟启动）

### 🧰 环境要求

| 依赖 | 最低版本 | 备注 |
|------|----------|------|
| ☕ JDK | **17+** | 低版本启动会报错 |
| 🟢 Node.js | **20+** | 建议 v20 LTS，v18 可能兼容但未测 |
| 🪶 Maven | **3.8+** | 配好环境变量（`mvn -v` 能输出版本） |
| 🌐 浏览器 | Chrome 100+ / Edge / Safari | 最新版 |

---

### Step 1️⃣ · 填你的大模型 API Key

打开：`travel-server-java/src/main/resources/application-dev.yml`

```yaml
llm:
  provider: deepseek            # 可选 deepseek / siliconflow
  deepseek:
    api-key: sk-xxxxxxxxxxxxxxx  # ⚠️ 替换成你的 DeepSeek Key
```

> 🪪 **免费领 Key**：
> - DeepSeek：https://platform.deepseek.com/api_keys（送新户 ¥10 体验金，约能跑 2 万次规划）
> - 硅基流动：https://www.siliconflow.cn/ （新户送积分，模型比 D 便宜）

---

### Step 2️⃣ · 启动后端（开一个 PowerShell）

✅ **推荐用这一行（跨盘安全，不会报 ENOENT）**：

```powershell
Set-Location "D:\TRAE SOLO CN\travel\travel-server-java" ; mvn spring-boot:run "-Dspring-boot.run.profiles=dev"
```

等控制台出现：`Started TravelServerApplication in x.xxx seconds` 就说明 **后端已就绪 ✅**。  
默认端口：`http://localhost:8080`

---

### Step 3️⃣ · 启动前端（再开一个 PowerShell）

✅ **同样一行命令复制粘贴**：

```powershell
Set-Location "D:\TRAE SOLO CN\travel\travel-h5" ; npm run dev
```

等控制台出现：

```
VITE v5.4.21  ready in xxx ms
  ➜  Local:   http://localhost:5174/travel-assistant/
```

👉 **浏览器打开 http://localhost:5174/travel-assistant/ 就能体验完整 AI 功能啦！🎉**

## 🧩 API 接口一览

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/travel/recommend` | POST | **智能规划（非流式）** 返回完整行程 JSON |
| `/api/chat/stream` | POST | **AI 对话（SSE 流式）** 逐块推送 `data: {...}` |
| `/api/travel/chat/stream` | POST | 同上（别名兼容历史路径）|

### 📤 请求示例 · 智能规划

```http
POST http://localhost:8080/api/travel/recommend
Content-Type: application/json

{
  "city": "成都",
  "budget": 3000,
  "days": 3
}
```

### 📥 响应示例 · AI 流式对话

**后端按 SSE 标准逐行推送：**

```http
Content-Type: text/event-stream
Cache-Control: no-cache
Connection: keep-alive

data: {"content":"成"}
data: {"content":"都"}
data: {"content":"的"}
data: {"content":"美"}
data: {"content":"食"}
data: {"content":"有"}
data: {"type":"done"}
```

前端通过 `fetch()` + `ReadableStream` 逐块读取，直接 append 到气泡，形成打字机效果。

## 🤝 贡献指南

不管你是第一次开源贡献还是老司机，都非常欢迎！按下面 5 步走：

1. **Fork** 本仓库 → 克隆到本地
2. 新建功能分支：
   ```bash
   git checkout -b feature/amazing-feature
   ```
3. 写完之后跑一下 build 确认没报错：
   ```bash
   cd travel-h5 && npm run build
   ```
4. 提交 + 推送：
   ```bash
   git add .
   git commit -m "feat: 某个很棒的功能"
   git push origin feature/amazing-feature
   ```
5. 发起 **Pull Request**，我会在 24h 内 review 合并 🎉
